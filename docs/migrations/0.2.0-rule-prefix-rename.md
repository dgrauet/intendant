# v0.2.0 — Rule prefix rename

**Breaking change.** Stack-specific rule IDs were renamed to use explicit stack prefixes.

## Rationale

The Node adapter (introduced in v0.1.14) used `NODE_*` prefixes (e.g., `NODE_PK001`). For
consistency, the same convention now applies to the Python and Claude Skill adapters. Future
adapters (Rust, Go, etc.) will follow the same pattern automatically.

## Rename table

### Python adapter

| Old | New |
|---|---|
| `LO001` | `PYTHON_LO001` |
| `LO002` | `PYTHON_LO002` |
| `PK001` | `PYTHON_PK001` |
| `PK002` | `PYTHON_PK002` |
| `PK003` | `PYTHON_PK003` |
| `PK004` | `PYTHON_PK004` |
| `QU001` | `PYTHON_QU001` |
| `QU002` | `PYTHON_QU002` |
| `QU003` | `PYTHON_QU003` |
| `QU004` | `PYTHON_QU004` |
| `TS001` | `PYTHON_TS001` |
| `TS003` | `PYTHON_TS003` |

### Claude Skill adapter

| Old | New |
|---|---|
| `SK001` | `CLAUDE_SKILL_SK001` |
| `SK002` | `CLAUDE_SKILL_SK002` |
| `SK003` | `CLAUDE_SKILL_SK003` |
| `SK004` | `CLAUDE_SKILL_SK004` |
| `SK005` | `CLAUDE_SKILL_SK005` |
| `SK006` | `CLAUDE_SKILL_SK006` |
| `SK007` | `CLAUDE_SKILL_SK007` |

### Unchanged (transverse rules)

`DG001`–`DG005`, `RL001`–`RL004`, `CI001`–`CI004`, `SA001`–`SA004`, `LO003`, `TS002` — these
rules apply to every stack (`stacks=("*",)`) and keep their existing IDs.

## Migration steps

For each governed repository whose `.suzerain.toml` declares an exemption on a renamed rule:

1. Open `.suzerain.toml`.
2. Under `[exemptions]`, rename each exemption key to its new prefixed form.

   Example:
   ```toml
   # Before
   [exemptions]
   LO001 = "fork upstream layout"

   # After
   [exemptions]
   PYTHON_LO001 = "fork upstream layout"
   ```

3. Re-run `suzerain audit . --severity=required` and confirm the rule is now reported as
   `exempt` instead of `fail`.

## Backward compatibility

None. The old IDs are removed entirely; suzerain v0.2.0 does not recognize them.

If you need a quick portfolio-wide migration, this one-liner renames common cases:

```bash
sed -i '' \
  -e 's/^LO00\([12]\) /PYTHON_LO00\1 /' \
  -e 's/^PK00\([1234]\) /PYTHON_PK00\1 /' \
  -e 's/^QU00\([1234]\) /PYTHON_QU00\1 /' \
  -e 's/^TS001 /PYTHON_TS001 /' \
  -e 's/^TS003 /PYTHON_TS003 /' \
  -e 's/^SK00\([1234567]\) /CLAUDE_SKILL_SK00\1 /' \
  path/to/.suzerain.toml
```
