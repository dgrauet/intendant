# 12 — Go

Convention de gouvernance pour les projets Go. Le Go adapter détecte les
repos contenant un `go.mod` à la racine. Les règles couvrent le strict
nécessaire pour un workflow Go reproductible : module déclaré, lockfile
checksums commités, version Go pinnée, linter configuré, tests présents,
CI complète, et binaires de test ignorés du VCS.

## Rules

### GO_PK001 — go.mod present at repo root with module declaration

**Severity:** required · **Stacks:** go

The repository must declare a `go.mod` at its root containing a
`module <import-path>` directive. Without it, the Go toolchain cannot
resolve dependencies or build the project.

### GO_PK002 — go.sum present at repo root

**Severity:** required · **Stacks:** go

`go.sum` must be committed at the repo root for reproducible builds.
Cargo `Cargo.lock` and npm `package-lock.json` play the equivalent role
for their ecosystems. For pure libraries with zero transitive dependencies,
this file may be empty but should still exist.

### GO_PK003 — go directive pinned in go.mod

**Severity:** recommended · **Stacks:** go

The `go.mod` should declare a `go <version>` directive (e.g. `go 1.22`).
Without it, the toolchain falls back to a permissive default that can
mask compatibility issues across contributor environments.

### GO_QU001 — golangci-lint config present

**Severity:** recommended · **Stacks:** go

A `.golangci.yml` (or `.golangci.yaml`/`.toml`/`.json`) at the repo root
makes the linter configuration explicit and reproducible. The rule
checks for the file's presence, not the content.

### GO_TS001 — at least one *_test.go file with a Test* function

**Severity:** recommended · **Stacks:** go

The repository must contain at least one `*_test.go` file with a
`func Test*(t *testing.T)` function (skipping `vendor/`). The rule
signals that tests exist; it does not enforce coverage levels.

### GO_CI001 — CI workflow runs go vet/build, go test, and a linter

**Severity:** required · **Stacks:** go

The CI workflow(s) under `.github/workflows/` must invoke a build/vet
step (`go vet` or `go build`), `go test`, and a linter (`golangci-lint`,
`gofmt -l`, `staticcheck`, or `revive`). Skipped when no workflows
directory exists (covered by transverse `CI001`).

### GO_SA001 — Go .gitignore baseline (*.test)

**Severity:** required · **Stacks:** go

The root `.gitignore` must include `*.test` to exclude compiled test
binaries left behind by `go test -c`. Skipped when `.gitignore` does
not exist (covered by transverse `SA004`).
